## 5. Habits this session paid for

- A Python `open(p,'w')` chained with `open(p).read()` truncated two files; write from a
  variable, never `open(p,'w').write(open(p).read())`.
- Watch deploys on the code-split chunk, not `bundle.js`; minified variable names are not
  greppable — grep a class name or a string literal.
- The `hidden` attribute is defeated by `.form-group { display: flex }`; use `display: none`.
- Read the backend gate's output before pushing; one push went out with a flaky suite that
  turned out to be a real same-millisecond key collision (`0da1edac`).
