One round, three screens, one next step

Owner, 2026-10-12: "Moving menus and buttons and having to do the same task differently, having unclear next steps or not moving things forward automatically when they should." Each moment of a Call & Answer round below: the host screen (the Stage above, the dock below), the Host Remote, and a participant. The primary is the same act, the same words and the same place on both host screens, because both read it from one function. The six pending features (name controls, Workie's pages, the question, host notes, follow-up asks, response stepping) fold into these moments; none of them adds a button to the round's path.
