Design notes
A place, not a sectionEditing a set is its own screen with its own breadcrumb. Today the editor appears below the list of forty-one sets, and the page scroll-jumps you to it and flashes it #fff3cd yellow for three seconds — a light-theme colour, on this palette, as the only cue to which row you are on.
Name the diffThe save button is pinned and states which fields are dirty. Today Save sits mid-form above two more panels, and the confirmation reports what the backend says it wrote — which is the right instinct, kept here and moved to where you can see it before you commit.
The questions were unreachableGET /question-sets/{setId}/questions has existed all along and no admin screen calls it. Until now, checking one bad row meant downloading the CSV.
Consequence, not dangerVersion delete already asks a real question — it names the games pinned to the version. Set delete, which is strictly more destructive, asks “are you sure?” and reports its result into a state variable that is never rendered.
