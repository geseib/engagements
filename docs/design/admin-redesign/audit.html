Audit

Six assertions over all 22 mockups at 1440×900 and 1280×800. Serve this directory — from file:// the frames are cross-origin and nothing can be read. Every check was written after a real defect it would have caught: A6 exists because a .ico with no width rendered at 300×150 in the jobs tray, and A2 because the first cut pinned design notes on top of four table rows.

A1 — no horizontal scrollNeither the document nor any scroll container inside it scrolls sideways, at either width.
A2 — nothing clips silentlyNo element loses text to overflow:hidden unless it declares an ellipsis or a line clamp that can actually render.
A3 — the 12px floorNo text below the floor derived in rationale §3.
A4 — WCAG 2.1 AAEvery text node ≥4.5:1 against its own background, or ≥3:1 at 19px bold / 24px regular.
A5 — target sizeEvery button and input at least 24px on its short edge (WCAG 2.2 2.5.8 minimum).
A6 — no unsized SVGAn inline icon wider than 40px is a missing width rule, not a design.
