Design notes
Validate before the round tripsummarizeCsv() already parses the file in the browser, quote-aware. It currently reports two counts. Everything on this page comes from the same parse plus the importer’s own published rules — no new endpoint.
“Skipped” is not a footnoteThe server does return skippedRowCount and the first fifty skippedRows with reasons, and the only place that surfaces is one sentence appended to a success message after the write has already happened.
Name the product’s own bugsThe poll Option1..5 vs Options mismatch silently empties every poll question, and the AI poll builder emits the broken shape. A design that hides a known defect behind a green tick is worse than no design.
