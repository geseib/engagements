Design notes
Keep the frame, empty itThe queue panel stays on screen with nothing in it, rather than disappearing. A section that vanishes when it is empty teaches you to stop looking for it — which is exactly the failure mode an approval queue must not have.
Not the same as no usersThere is no honest “no users” state on this screen: an admin is reading it, so at least one account exists. Drawing that empty state would have been drawing a screen nobody can ever see.
