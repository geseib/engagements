New engagement — redesign mockups

Design only, 30 Oct 2026. The create-engagement modal (GameSetupDialog.jsx) redrawn for a host who has never used Engage and a host who uses it every day. Real formats, real copy from config/gameTypes.js, real sets from demo-sets/. Previews marked “sample” are illustrations of the room, not live data. Read README.md beside this file for the problems, the bug’s root cause and the implementation map.

Motion: each format’s preview loops a few seconds of what the room does. With prefers-reduced-motion every preview shows its end state, still.

1

A first-time host opens the modal

Nothing is pre-chosen. The format step is a gallery: every format shows itself in a few seconds of motion, and hovering or focusing a card plays it large on the right with what the room does, what the host gets and how long it takes. The questions step waits, greyed, until a format exists to filter by.

Novice Reads the cards top to bottom, or clicks one of the seven “What do you want from the room?” answers to light the matching card. Sees the big preview before committing.

Expert Never sees this again after the first create — or presses “I know these” right now.

3

An experienced host: the compact path

After the first create (or “I know these”) the gallery is a single row of format chips, the last-used format is pre-selected and marked, and sets this host used lately are one click under the search box. Title → Enter → ← → for format → pick a recent set → Ctrl+Enter. The side pane stops playing previews and becomes a terse checklist.

Novice —

Expert Five keystrokes and two clicks: type a title, Tab, (format already right), click “Ready or Not” under Used by you lately, Ctrl+Enter. Nothing on screen explains what they already know; “Format guide” brings the gallery back for one look.

5a

Changing the set — the chooser takes the room

Change opens the chooser in place and it gets the whole modal body: the preview pane steps aside for the duration (the modal’s outer size never moves). The old set’s categories are gone at once — they describe a set the host is replacing — and one line holds their place. The current set is marked in the table, and “Keep the set I had” restores everything as it was.

Novice Can scan names and descriptions at full width instead of in half a column beside stale chips.

Expert Types “ready”, Enter.

5b

…and the categories refresh, with nothing jumping

Picking Ready or Not folds the chooser, brings the side pane back, and swaps the categories: the old chips never render against the new set. While the fetch is in flight the block keeps its height with skeleton chips (left, shown side by side here for the frame only); then the four new categories arrive, all on, with one sentence saying the earlier picks were cleared because they belonged to the other set.

Novice Is told plainly why their category picks changed.

Expert Same — and a stale response from the old set can never overwrite the new one (see the root cause in the README).

Event: chosen, and the hand-off

Next: the event’s day and agenda

An event is an agenda behind one join code
