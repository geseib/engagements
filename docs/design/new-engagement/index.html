New engagement — redesign mockups (revision 2)

Design only, 30 Oct 2026, revised after three reviews (first-time host, experienced host, visual and accessibility; in reviews/). The create-engagement modal (GameSetupDialog.jsx) for a host who has never used Engage and one who uses it every day. Real formats, real sets from demo-sets/ where they exist. Previews are illustrations of the room. Read README.md for the bug’s root cause, the decisions, the review changes and the implementation map.

Motion: a format preview plays once, in under five seconds, when its card is hovered, focused or chosen; the side-pane preview plays once when it appears and has a Replay button. Everything else stands still in its end state, which is also what prefers-reduced-motion shows.

3

Experienced host: the set picker before a pick

Compact mode is genuinely compact: one column in a narrower fixed card (880px), no side pane (a “Show preview” toggle brings it back), no helper copy, no Required pills. The last-used format is pre-chosen and labelled “last used”. Tabbing into the search shows the three sets used lately as a small list right under it — the body does not switch to the full chooser. ↓ and Enter pick; typing or “Browse all 15 sets” opens the full chooser (frame 5a). “Your question sets” and “Make a new set” stay beside the picker, as today.

Experienced host Title (focused on open) · Tab · Tab · Enter · ⌘↵ = four keys after the title. Remembered across devices because it is read from their own session history (README §8).

Keyboard Title → Tab → format radiogroup (one stop; ←/→ moves the choice, but the set is remembered per format while the dialog is open) → Tab → search, recents shown → ↓/Enter → ⌘↵ (Ctrl+↵ on Windows and Linux).

7

Build Room: the hand-off, and a shortcut that cannot leave by accident

The hand-off tiles are unnumbered (ticks and arrows), so the only numbers on screen are the form’s steps. The button names the destination. ⌘↵ / Ctrl+↵ does not leave the dialog for a hand-off format: it moves focus to the Continue button and the foot says “Press Enter to continue”, so arrowing through the format chips and then pressing the shortcut can never navigate away unseen. The set the host had for Call & Answer is kept for the dialog’s lifetime, so arrowing back restores it.

Experienced host Arrowed past Build Room by accident? Nothing happened: the set is still there when they arrow back.
