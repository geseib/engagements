New engagement — round 4: show the next decision, not all of them

31 Oct 2026. The owner: “i wonder if it would be less daunting if we revealed the sections as needed? As this seems overwhelming to a newbie.” Frames 4a–4d are a first-time host’s sequence at 1440×900; 4e is a host with history; 4f and 4g are the short laptop and the phone. Two forks are drawn after them, each with its recommendation. Notes, rules and the build list are in README.md under “Round 4”; the review is reviews/round-4.md. Round 3 is index-3.html.

The rule, in one line: a section appears when the decision above it is made, and never goes away while the dialog is open. A host with history starts two decisions in, because their last format is already chosen.

Reveal rules
SectionShown whenHidden again when
Name itAlwaysNever
FormatAlwaysNever
Question setA format is chosen (on open, for a host whose last format is preselected)Never for a session format. Build Room or Event puts “Next: the … page” in the same slot; choosing a session format again brings Question set back with the set it had
TopicsA set is picked (unchanged)The set is cleared or the chooser is open (unchanged)
Names card, Background for Workie, AdvancedA set has been picked at any point while the dialog is openNever while it is open; each shows only for the formats it applies to, as today. A hand-off format hides them with Question set
Create (foot)Always; filled once title, format and set are inNever. Until then outlined, with “Still needed: …”
Edit modeEverything, from the start—

Cut for everyone

  • Step numbers and ticks (1, ✓, 3). They counted steps you could see waiting; nothing waits on screen now. A finished section shows its answer, which is the tick.
  • The side pane’s status line (Title · Format · Questions). The foot’s “Still needed: …” says the same thing, beside the button it is about.
  • “OPTIONAL — EVERY ONE HAS A SAFE DEFAULT”. Each of the two lines says “Optional” or “Defaults” itself, in sentence case.
  • The Advanced line’s full sentence. Closed, it names only what the names card does not already say (“Defaults: questions shuffled, Workie’s standard summary”), or “Changed: …” in amber; the full sentence is inside.
  • The gallery’s mini pictures. The pane beside them draws the same thing three times larger and follows focus.
  • “Your question sets” for a host who has none: one link, “Make your own set”.

Changed after the round-4 review (reviews/round-4.md)

  • Create is never inert. It was a disabled button, so a keyboard or screen-reader user tabbing past Cancel never reached it or heard why. Now aria-disabled and described by the foot’s “Still needed: …”; pressing it (or ⌘↵) moves focus to the first missing decision and says which.
  • One announcement per action, once per reveal. Arrow keys choose in the format group, so “Question set added below” would have spoken on every arrow. It speaks on the first reveal only, joined to the meeting chip’s reason when a chip caused it.
  • The entrance plays once. Switching format inside a revealed section swaps its contents with no animation.
  • The pane’s example says it is one (“Example · Call & Answer, stage 1 of 6”), and how to see the others. Dana read the old caption as a recommendation.
  • The Advanced line names the two defaults the names card does not (Sam checks “shuffled” before every create).
  • “Something bigger?” → “Bigger than one session”, with a three-word line each. It read as an upsell.
