Build Room: building with Claude Code, together

Storyboard prototype for PLAN.md in this folder. The room is building a volunteer sign-up site for the Eastside Food Bank. The host's laptop is on the projector, the host's own Claude Code runs in a terminal, and about eighteen people in the room hold phones.

How to read this. Each frame has a caption and one line on why it is drawn that way. Host controls use the laptop ladder (12 / 13 / 15 / 19 / 24 / 30px). The wall frames use a larger stage ladder, drawn here at frame scale, so judge them full-width. Content is static; nothing here talks to an API.

PPresent mode: what hides

The laptop stays on the projector all session. Present (a toggle in the host bar, also P on the keyboard) removes everything the room should not see or cannot use. The host works on a phone at /build meanwhile.

ElementPresentWhy
Close / Open voting / Reopen / Discard buttonsHiddenControls the room cannot press are noise on the wall.
Proposed (unreviewed) asksHiddenThe review gate is the point; the wall keeps showing the ticker.
Ideas inbox, with namesHiddenUntriaged and attributed; may hold something not for the room.
Host notes (note log kind)HiddenNever shown to the room or Claude.
Names on reasons and suggestionsHiddenThe wall is anonymous; names live in the host view and report.
Connect panel, key, prompt cards, settingsHiddenThe key must never be projected.
Question, letters, bars, counts, join code, QRShownThis is the wall.
"Claude Code connected" chip, ticker, timelineShownKeeps the room engaged between asks.
