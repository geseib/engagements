Two codes the room can scan: Join, and the demo

Owner, 2026-10-11: "the settings for build room should have two QR codes, large enough for the room to see: the Join QR and the Demo QR link." Today Settings shows the join code as a number and a button that opens the Join QR on the wall; the demo's QR is 72px inside the inline Share demo panel. The host's laptop is often on the projector, so a code in the panel is also a code on the wall.

Three options

A · Both codes in Settings

The room group leads with two codes side by side: Join always, the demo when it is shared. When it is not, the demo's slot says what to do: Share demo if Claude has shown a running app, No demo yet if there are only screenshots. Each code carries its short address and one line.

Big enough for the host to test with a phone and for the front rows on the projector (about 3 m). Not for the back of a room: the panel is 560px wide.

B · One move: both codes on the Stage

Settings keeps today's rows and gains Show both on the Stage. The Stage shows a two-code card, Join left, demo right, on the Room ladder. With no demo shared it is today's Join QR alone.

Readable across the room (about 6 m). But Settings itself still has no code to scan, which is what the owner asked for.

C · Both Recommended

A's two codes in Settings, and its one orange button puts them on the Stage as B's card. The panel is where the host checks the codes work; the Stage is where the room reads them. One element per job.

Also retires the 72px demo code and the inline Share demo panel: the demo tile does that panel's job in every state.

C · Settings on the projector: demo shared, 11 of 18 opened it

The Session panel over the Host screen at 1440. The two codes lead the room group, each 232px: on a 90-inch projected image that is about 31 cm, enough from about 3 m. Show both on the Stage is the one orange button; it puts the same two codes on the Stage at 430px for the rest of the room.

Sizes, and why

Both links are QR version 4 at level M (the app's setting): 33 modules, 41 with the quiet zone. Projected sizes assume a 90-inch 16:10 image showing a 1440px-wide screen, so 1 CSS px is about 1.35 mm. Scan range uses the usual rule of thumb: a phone reads a code from about ten times its width.

Open questions

  1. Show "No demo yet" at all? The slot teaches where the demo will appear, but it is a second thing on screen before there is anything to share. The alternative is the Join code alone, wider, until demoRunnable.
  2. One orange in Settings. The shipped inline Share demo panel has no orange on purpose, and the Session panel mockup kept Players free of it. These frames give the room group one. Agreed?
  3. One Stage card for codes. Should the Share demo chip's "Show on the Stage" also open the two-code card, retiring the demo-only card (WallBuildQr)? These frames assume yes, so the Stage has one place for codes.
  4. The header join button keeps opening the single big Join QR. Or should it open the two-code card while the demo is live?
  5. Quiet on the Stage. These frames keep the demo code up while nobody has opened it. Take it down after 2 minutes instead?
  6. Remote link, later. When there is both a Wi-Fi link and a remote one, show the remote one (it reaches everyone) and list the Wi-Fi one under it?
