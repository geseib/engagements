Design notes
Everything that has a safe defaultResponses, question order, Workie’s voice and approach, instructions and event details. Each keeps its shipped control and copy (GameSetupDialog.jsx:542-739); only the grouping and two labels change.
A change is named in the summaryThe voice was switched, so the summary leads with Changed: Workie speaks as The Business Advisor in amber, then the defaults still in force. Close the section and the decision is still on screen.
‘AI context’ says what it doesRenamed Instructions for Workie. The prompt already treats it as the host’s rules: it rides the last block with ‘EVERY section must contain…’ enforcement (personas.js:488-529). Facts about the situation belong in the briefing, which is weighted differently (40).
Event details: who sees itGrouped under What people see when they join, because that is its main job (GameSetupDialog.jsx:644-647); it also reaches Workie as ABOUT THIS SESSION (personas.js:655-657).
Consistent with the survey startResponses is Call & Answer only: polls lost their vote phase on 23 Sep, so anonymityApplies narrows from three formats to one (config/anonymity.js:19-21). A survey, when it ships, shows the three-way Names choice here instead — survey-redesign 07 re-cuts this same card.
Room settings stay on the stageAuto-advance, names while waiting and comments on the wall are judgements about this room at run time (config/gameSession.js:122-137) and stay in the stage’s Setup panel. Advanced holds only what the session is.
