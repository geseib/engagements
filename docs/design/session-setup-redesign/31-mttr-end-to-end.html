Design notes
What moves from the file to the wallOnly facts: two numbers, one ratio, one cause, one goal. The document’s names, its table and its other twelve pages stay behind. The wall shows Workie’s words, never the briefing itself.
Where Workie’s own knowledge comes inThe shipped Call & Answer default forbids it: ‘You know nothing else about this room, this company or this industry’ (rule 1, admin/default-ai-prompts.json:6). The briefing block widens exactly that rule for a briefed session: general professional practice, said as general practice. The owner’s example needs both halves.
Where it enters the promptLast, after the host’s required additions (get-ai-summary.js:2536): that position is the one the game 1935 and 4567 experiments showed a model obeys (personas.js:464-529). See 40 for the block, word for word.
What would make it wrongSaying ‘someone said MTTR is three weeks’ (a brief fact as a participant’s); inventing ‘cut MTTR by 40%’ (a number not in the material); naming the director. Each is a line in the block and an assertion in tests/briefing-prompt.js (PLAN phase 3).
