Create an engagement, and preview it

Three pieces from one brief (owner, 23 Sep). A simpler create dialog: the few things a host must decide up front, everything with a safe default under one Advanced disclosure whose summary line names the defaults. A briefing from a document for Call & Answer: a PDF summarised into a short, editable brief that Workie uses when it reflects the room’s answers. A preview: after creating and before opening, the host looks at the stage, steps through, and edits — with the doors closed. The dialog pages are drawn by the shipped GameSetupDialog.css; the stage, phone and console by their approved mockup sheets. Press N on any page to hide the design notes. See RATIONALE.md and PLAN.md beside this file.
