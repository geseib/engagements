# 0d: The setting

Engage can now switch skins for everybody. Engage staff pick one under **Engage settings →
Site look**, the choice goes into one platform row, and every page reads it back from a
public `GET /site` (SPEC §5).

## Deviations from the prompt and SPEC, and why

1. **Path corrections.** `template-clean.yaml` is at the repo root, not `src/src/`. `public/index.html` already existed: I edited it, I did not create it.
2. **Ownership exceptions: two files outside 0d's list.** Each is one line, and no unit in any wave owns either file.
   - `lambda-functions/admin/orgs/platform-orgs.js`: its dispatch regex was `/platform/settings/claude-models$`. Without widening it to `/platform/settings/[^/]+$`, `GET /platform/settings/site-skin` falls through to `listOrgs` and the feature cannot work.
   - `src/src/components/Icon.jsx`: added `SlidersHorizontal` to the import and the map. Without it, the icon SPEC §5.4 names renders as the `Circle` fallback.
   If the coordinator wants these split out, both edits sit inside `49cf15e6` and `98b76a71`.
3. **No per-skin swatch in the panel (SPEC §5.4).** The swatch cannot render as drawn. Skin values are declared on `:root[data-skin="<id>"]`, so a `data-skin` on a nested `.ui-skin-swatch` matches no selector and every swatch would show Classic. Making it work would need a second selector in the skin files, which `skinPalette.test.js` forbids. The preview is the whole page instead, through "Preview X in this browser" (SPEC Q7). `SiteSkinPanel.jsx` therefore sets no `data-skin`. The gate still allows it there, unused.
4. **The gallery path is `/skins`, not `/skins/gallery` or `/dev/skins`.** `setMediaStorage.test.js` pins every multi-segment route, because a nested route breaks the relative `sets/<id>/x.jpg` image keys, and gallery fixtures will render questions.
5. **The gallery is not excluded with a `NODE_ENV` guard.** Every tier ships the same production build, so that guard would remove it from dev too. It is gated on `window.ENV` and lazy-loaded, so no other tier ever fetches the chunk.
6. **The staff panel's Save is a quiet button, not `--action`.** The Claude models switch above it already holds the screen's one orange (R3).
7. **The `App.jsx` JSX literals stay (3).** They are in `AuthLoading`/`ProtectedRoute` inline styles, which the plan gives to W7-c's sweep. The prompt's notes limit App.jsx to the provider edit, so I kept them.
