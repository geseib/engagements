SPEC ambiguities resolved:
- **Danger ink.** SPEC lists `--danger-deep` but no ink. `--text` is navy on paper (2.6:1 on
  `#B03A34`), so the ink is the theme-invariant glow channel `rgb(var(--glow-rgb))` (#F4EDE4 in
  both skins): 5.16:1 everywhere, the value styles.css documents for `--danger-deep`.
- **The wall hover.** roles.css re-points `--action`/`--on-action` under
  `[data-surface="wall"]` but not `--action-hover` (orange in both skins). A hover reading it
  would paint orange on the Present wall, so `[data-surface="wall"] .ui-btn--action:hover` keeps
  `--action`. Asserted. A future `--wall-action-hover` value would be the cleaner fix (0a/roles
  owner's call, not this unit's).
- **Size.** SPEC: "sizes come from the surface's ladder". `font-size` is `var(--ui-size, 1em)` on
  `.ui-btn` only; `sm`/`lg` set `padding` and `min-height` in em, nothing else (asserted).
- **Focus ring.** `--accent-text`, not `--accent`: on paper `#F6A94C` is 1.96:1 on white; the
  ring clears 3:1 (WCAG 1.4.11) on bg/surface/surface-2 in every case (lowest 4.63, Classic paper
  surface-2).
- **Default variant** is `quiet` (SPEC gives none): "one orange per screen" makes `action` the
  deliberate choice, never the default.
