## Decisions

`codemod.js --report --theme dark+light`: auto 0 · decide 0 (no literal, no `--primary`/`--secondary`
to decide). Decisions file: `records/L1.decisions.json` (empty, kept as the evidence). No `keep:`.

SPEC ambiguities resolved here:
- **Size hook name.** SPEC §6 says a surface passes size "by class or by a `--ui-size` property". A custom property inherits, so one generic `--ui-size` set for a heading would also resize every eyebrow beneath it. Each component gets its own hook instead: `--ui-eyebrow-size` here. Unset, the eyebrow takes the surrounding size (`1em`).
- **Margin.** `margin: 0`. `.present-eyebrow` has `0 0 .6em`, `.kicker` none; spacing stays with the adopting surface (its class, passed through `className`).
- **Tone names.** `muted` and `accent` are skin-independent overrides; `accent` reads `--accent-text` (copy), never `--accent` (a fill colour, under AA as text on paper).
