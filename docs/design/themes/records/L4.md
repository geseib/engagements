### SPEC ambiguities resolved

- **Ink is `--on-accent`, as SPEC §6 lists, not `.present-badge`'s `var(--bg)`.** `--on-accent` is
  `#1B2942` in both skins; the Presentation's badge today paints `#0F1A2E`. When P2 adopts this
  badge the Presentation's badge ink moves `#0F1A2E → #1B2942` (both skins; 8.86 → 7.42 on
  Classic orange, 7.06 → 5.91 on Present blue). That is P2's change to record, not a Classic
  delta here (no screen adopts the badge in this phase).
- **`size` is a CSS length, not an enum.** SPEC §6 says sizes come from the surface's ladder
  variable; an enum would have to invent steps. A number means px.
- **Muted tone is a ring, not a fill.** Muted ink must read on whatever ground the badge sits on;
  without a fill it does on all three dusk and all three paper grounds.
