## Component

`components/ui/TallyRow.jsx` + `TallyRow.css`, scope `.ui-trow`. A port of the Presentation's
results row (`PresentTally`, `.present-trow`): a three-column grid, rank · who · points.

| Prop | Meaning |
|---|---|
| `rank` | the place, `--muted`, display face 700, tabular figures; omitted → empty cell |
| `label` | the row's name, `--text` 600 |
| `sub` | the line under it (first words), `--muted`, one line with an ellipsis; its full text is its `title` (hard rule 7) |
| `share` | 0..1 → a `--accent` bar, `width: max(3, round(share*100))%`, capped at 100; null/undefined/non-numeric → no bar |
| `points` | tabular figures, `--text` 700, then `unit` in `--muted` small; null/undefined → an empty cell so a list's columns line up; `0` shows |
| `unit` | default `'points'` |
| `size` | the row's ladder step (CSS length / `var()` / px number) → `--ui-size` |
| `as` | element, default `div` (`li` inside an `<ol>`) |
| `className`, `style`, rest | appended / passed through |

Exported: `barPercent(share)`, `BAR_MIN_PERCENT = 3`. Everything is in em of `--ui-size`, at the
Presentation's Room proportions (secondary 40px, meta 21px): rank column 1.4em, gap `.6em`
(`--ui-trow-gap`), first-words `.525em` (`--ui-size-sub`), bar `.35em` (`--ui-trow-bar-h`),
unit `.55em`. Gallery fixture: `components/ui/fixtures/TallyRow.jsx` (a 4-row list: bars, one at
the 3% floor, a long first-words line, a row without points).

### SPEC ambiguities resolved

- **Added `unit`** beside SPEC §6's props: the Presentation hard-codes "points"; poll rows say
  "votes".
- **The bar is capped at 100%** as well as floored at 3% (the Presentation only floors).
- **Fixed px in the Presentation become em** (the 24px gap and `14px * --fit` bar): equal at Room;
  at TV/Table P2 sets `--ui-trow-gap` and `--ui-trow-bar-h` to keep its pixels.
- **`title` on the cut first-words line** (hard rule 7); the Presentation has none (the wall has
  no pointer, so it is harmless there).
