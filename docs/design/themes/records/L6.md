# L6: Pips

A new component, born on roles, dusk only (units.json). Built on `skins/L-g3` (the group
branch), not `skins/L6`.

## Component

`components/ui/Pips.jsx` + `Pips.css`, scope `.ui-pips`. A port of the Presentation's `Meter`,
page pips (`ReadPage`) and navigator track (`trackOf`, `present/navigatorWindow.js`).

| Prop | Meaning |
|---|---|
| `variant` | `'meter'` (default) · `'pages'` · `'track'`; unknown → meter |
| `done` | meter: how many are done · pages/track: the 0-based index of the one on screen (clamped) |
| `of` | meter: how many there are · pages: page count · track: response count |
| `seen` | pages only: how many pages have been read; default `done` (every page before the current one, exactly `ReadPage`) |
| `label` | words for the whole indicator → `role="img"` + `aria-label`; without it `aria-hidden` (the surface states the position in text, as the Presentation's foot does) |
| `className`, `style`, rest | appended / passed through |

Exported: `PIPS_MAX = 24`, `pipsModel(variant, done, of, seen)`. **Caps at 24:** the meter scales
`done` onto 24 pills (the `Meter` arithmetic) and turns `is-all` (green) when everyone is done;
track and pages past 24 become one bar (`is-bar`) with a marker at `index / (n - 1)` via
`--ui-pips-at`.

Colours (roles): pill `--surface-2`, on/marker `--accent`, all `--success`, seen
`--ui-pips-seen: rgb(var(--accent-rgb) / 0.45)` (the Presentation's `--present-seen`, channel
form). Sizes default to the Presentation's 1920x1080 pills (meter 44x12 gap 8, pages 48x10 gap
10, track 30x10 on 56 gap 6, bar 640x10 with a 12x20 marker) and are overridable per surface:
`--ui-meter-*`, `--ui-pages-*`, `--ui-track-*`, `--ui-bar-*` (listed in `Pips.css`). Gallery
fixture: `components/ui/fixtures/Pips.jsx` (every variant and state at laptop sizes, labelled).

### SPEC ambiguities resolved

- **What `done` and `seen` mean per variant** (SPEC §6 lists only the names): `done` is a count
  for the meter and a position for pages/track; `seen` is a count of pages read, defaulting to
  the position so the Presentation's behaviour is the default.
- **Pages past 24** take the track's bar rather than scaling (a scaled page pip would no longer
  be one page).
- **The pills keep the Presentation's px sizes as defaults** (SPEC §6 says sizes come from the
  surface): any other surface passes its own; the defaults let P2 adopt it pixel-for-pixel.
- **`align-items: center`** on every variant (the original meter did not set it; its pills are
  all one height, so it is the same picture).
