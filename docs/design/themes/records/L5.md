A new component, born on roles. Built on `skins/L-g3` (the group branch), not `skins/L5`.

## Component

`components/ui/Card.jsx` + `Card.css`, scope `.ui-card`.

| Prop | Meaning |
|---|---|
| `selected` | adds `is-selected`: border `--accent`, `box-shadow: var(--select-mark)`. The mark is read in that one rule only |
| `badge` | a number/text → a `NumberBadge` (L4) at the head of the card; a React element → rendered as given; `null`/`false`/`''` → none; `0` is a badge |
| `head` | what sits beside the badge in the head row (a name, "Response 7 · name hidden"); shown only with a badge |
| `as` | element, default `div` (`li`, `article`, `button`…) |
| `className`, rest | appended / passed through |

Sizes are the caller's custom properties, with defaults: `--ui-card-pad` (16px 20px),
`--ui-card-border` (the hairline `--hair`, 1px), `--ui-card-gap` (.55em = 22/40, the
`.present-card-head` gap), `--ui-card-head-gap` (.6em = 24/40), and the badge's `--ui-size`
(inherited). Roles read: `--surface`, `--text`, `--rule`, `--radius-lg`, `--accent`,
`--select-mark`. Gallery fixture: `components/ui/fixtures/Card.jsx` (plain, selected, badged,
badged + selected; dusk and paper).

### SPEC ambiguities resolved

- **`head` is added beside SPEC §6's `selected`, `badge`, `as`.** "Optionally badged" needs
  somewhere for the line next to the badge (the response card's name/meta); without it a caller
  would rebuild the head row and its gap.
- **The unselected border is `--rule` at the hairline; the Presentation's response card is a 3px
  `--accent` border always.** It is "the selected card" of the navigator, so P2 adopts it as
  `<Card selected style={{'--ui-card-border': '3px', '--ui-card-pad': '44px 56px 40px'}}>`.
  Note for P2: under Present `--select-mark` then also paints its 3px left inset; and
  `--radius-lg` is 16px (Classic) / 20px (Present) where `.present-card` is 28px at 1920 (SPEC Q4).

(`--accent`) is under WCAG 1.4.11's 3:1 against the card in both skins — Classic `#F6A94C` 1.96:1

then the pin should become ≥ 3). A paper caller whose selection must read should also say it in
words (`aria-current`, a label). A fix would be a paper-only selection role (e.g. `--accent-text`,
5.07 / 6.26 on white).
