What counts, and what "seen" means

The count is new since seen. "Waiting for you · N" on the Host screen stays the count of what is still to handle. Opening a line marks it seen; the item stays in Waiting for you until the host acts on it.

Line, in this orderCounts whenJumps toFolded
Claude has a questionClaude proposes an ask (status: proposed, source: agent) with no mockups. Claude is blocked on it. Turns the count amber.That ask in Waiting for you, focused"Claude has 2 questions", to the oldest
Mockups are ready (3)A Claude ask's mockups are all in (mockups.ready). Claude waits on this too, so it is amber as well. (3) is the number of pictures.That ask, its tiles in viewTwo votes ready: "2 votes are ready"
Claude finished: header builtClaude posts a showing or milestone, or a doing line ends. The text is Claude's own done line, already room-safe (build-room-doing). Grey.That entry in the History column"Claude finished 3 things"
3 new ideas from the roomNew ideas from participants (status: new, not the host's own), and crew early looks. Never their text or a name. Grey.Waiting for you, Room filter onAlways one line
Not countedThe host's own drafts and queued ideas (the host made them). A request to take a name: SESSION already carries that nameless count, and the Session panel handles it. Progress posts and the doing line: the screen already shows them.
