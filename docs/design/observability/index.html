What each number means

Created
A host made a session, whether or not it was ever played.
Started
A session left the lobby — Start, or its first question from the remote. Once per session.
Toward plans
What each team’s Plan & usage counted that month, summed across every organisation.
Questions
A question counts when it is put on screen, once per session. Questions a set holds but nobody reached are not counted.
Per session
Questions ÷ sessions that put at least one question on screen, that month.
Answers
One per person per question. Changing an answer does not count again.
