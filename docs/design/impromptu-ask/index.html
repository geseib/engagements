Your own question, queued

Owner, 2 Nov 2026: "Host in call and answer can create a improptu ask and queue it up." Read as: mid-session, the host writes a Call & Answer question of their own and puts it in the running order, next or at a chosen place. It then runs as a normal round: answer, vote, results, Workie's read. The details are in README.md. This is a mockup only.

The new words are Write a question (the way in), Put it next / Put it later / Ask it now (where it goes) and the Yours mark (on host surfaces only). There is no new surface. The composer is one step inside the Session menu's Rounds section, and the rail and the phone Remote are two more ways into that same step.

1 · Start it: two doors into one place

Two screens, Round 3, Workie's read is up. The host thinks of a better question for the room.

  1. Rail, Round queue: a new quiet link Write a question sits under the rounds, beside the existing Rounds and questions link. It opens the Session menu at Rounds with the composer already open.
  2. Session menu → Rounds → Running order: Write a question sits at the right of the Running order heading, because that heading is where the question will land.
  3. No new button in Your part now, the top bar or the dock. The orange button stays the room's next step.

2 · The composer: a step inside Rounds, not a new dialog

  1. The question (required, up to 200 characters): what the room sees and answers.
  2. A line for the room (optional, up to 400): shown under the question, like a set question's detail.
  3. For Workie only (optional, up to 400): what you hope to learn. Never shown to the room or on any phone. It is stored where a set question keeps its private Background.
  4. How the room answers is not a choice: it runs like every round. The composer says so in one line.
  5. Where it goes: Next (the default), Later (after a round you pick), or Now (only between rounds; while answering or voting is open it is greyed out and says why).
  6. The foot has Cancel on the left and the commit on the right, and its label follows the choice: Put it next, Put it after round 5 or Ask it now. The X, Cancel, ← Running order and Escape all go through one requestClose(), which asks first when something has been typed.

3 · In the running order: marked Yours, editable until it runs

  1. A status line in the Rounds section confirms it: "Your question is next. It starts when you press Next round." The line has Undo.
  2. Your part now names it, so the orange button's meaning is never a surprise: "Next round asks your question."
  3. The row carries Yours (pen icon and the word) everywhere a running order is drawn: the Rounds section, the rail's Round queue, Setup's First up and the Remote's Rounds tab.
  4. Row actions are Edit (reopens the composer with the words), earlier and later, and Remove. Disable for this session is not offered, because there is nothing in the set to disable.

5 · One screen: the composer never draws on the room's screen

  1. On one screen the laptop is the room's screen. Write a question in the Session menu (or on the slim rail link) opens a host-only choice. It never opens the composer straight away.
  2. On your phone is the first choice when the Remote is connected. The composer is already open there under Rounds. With no Remote connected, the choice reads Connect your phone (experience plan §3.3).
  3. Write it here is allowed, but it says plainly that the room will see the typing. It suits a host who wants to write it with the room.
  4. The phone Remote's composer is the same fields in a full-height sheet. Its commit is the Remote's one orange button.
