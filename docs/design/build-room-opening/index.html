The Build Room opening: frame it with the room, then build

Owner, 2026-10-06: start wide open, narrow with the room ("pick from a list or spin a wheel"), probe like Amazon's working backwards (who is it for, what problem exists, what would good look like), then what we are building and with which tools. When that is done, Claude goes from planning and prep to build mode. Answers: a guided path the host can skip; the host answers Tools by default; Claude prepares, proposes probing questions and drafts the brief.

O1 · Host: the opening starts with "What are we making?"

The Now card carries the opening's path. Step 1 is a pick from a list the host can edit (up to six, so it fits the wheel). The room picks, the wheel picks, or the host picks for the room. The brief on the right starts empty and fills as each step is decided.

2Ask, spin, or pick

The same three ways for every pick step. The room's answers come back as a vote; the wheel and a revote settle a tie.

3Start building, any time

The opening never blocks. Start building sends the brief as it stands to Claude as Do now, and the session moves to building.

Nine lines in Amazon's working-backwards order, one per step: done, asking now, or next. Click a line to ask it, skip it, reword it or ask it again. 1Each step is an ordinary ask

Ideas, then a vote, with the wheel or a revote on a tie, exactly as today. Answer for the room and Skip are always there.

2Claude probes, the host decides

Reading the brief, Claude proposes a probing question as a proposed ask, saying why. Ask it next runs it as the next step; its answer joins the same brief line.

3The host's own probes

Each decided step offers short probes (Who else? Who is it not for? What do they do instead?). One click asks it.

4New lines show as new

The line that just changed carries a mark, so the host sees what the room added.

5Claude drafts the brief

Once Making, For, The problem and Good looks like are known, Claude drafts the one page (O3) for the host to edit and show.

O3 · Stage: the build brief on the wall, then Start building

The room reads back what it decided, as the start of a press release. The host presses Start building (or Space): Claude gets the whole brief as Do now and moves from planning to building.
