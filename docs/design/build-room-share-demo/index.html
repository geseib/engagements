Open questions

  1. "Demo" or "build"? These frames use the owner's "demo" for everything shared ("Share demo", "Open the demo") and keep "Open the build" for the host's own link. Rename W.openBuild to "Open the demo" everywhere instead?
  2. Ask to try it. It gives people off the share a voice and is the only thing that brings the chip forward after Not now. Keep it, or is that the nagging the owner ruled out?
  3. Only screenshots, no link. The gateway needs a local address to forward. When Claude has shown only screenshots, Share demo would also tell Claude "the host wants the demo shared: post its local link". Agreed?
  4. (c) needs the gateway to report which device arrived (a per-player tag on the link). Without it, (c) falls back to a plain "Didn't open?" link always shown under the button. Worth the plugin bump?
