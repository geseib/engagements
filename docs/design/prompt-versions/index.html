Prompt versions, and updates from the repo

For the owner, 21 Oct. Prompts get versions as question sets have them. The prompt files kept in the repo travel with each deploy, so the library can say when one differs from what is live. Nothing is ever overwritten: every change is a new version, and any earlier version can be made live again. The admin console's own type sizes and paper style; the prompts are the real four that need the next-steps fix.

1 · The library says which prompts have a newer version in the repo

A notice above the table counts them, and each row carries the mark in its State column. "Repo has a newer version" appears only when the live text differs from the repo's file for that prompt; it never updates anything by itself.

Each part of the prompt shows what changes, with the words added and removed. If someone edited the live prompt here since the repo file was written, a warning says so and saving keeps their version in the history. Save as version 2 makes it live; version 1 stays, one click from live again.

3 · Versions, in the prompt editor

A Versions tab beside Edit lists every version: when, who, and how it was made (an edit, an upload, the repo). View one, compare it with the live one, or make it live again (press twice). Sessions already running keep reading the live version; nothing is deleted.
