Claude models switch

One Engage-wide setting, for every team and for Engage's own calls. On (the default): Claude calls go to the Anthropic API's 5.5 models. Off: they stay on Bedrock's 4.x models, exactly as before. Any call that fails on the Anthropic API is answered by the Bedrock model instead.

1 · Laptop: on, the default

Engage mode, Engage settings. The switch's track is the one orange on the screen. The two rows say exactly which model replaces which; nothing else changes.
