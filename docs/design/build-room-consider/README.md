# Build Room: the console's layout (d), and Consider with sent marks

Mockup for the owner, 19 Oct 2026. `index.html`, frames rendered as PNGs here.

Owner, 19 Oct, on the console mockup's five questions: "use the recommendations for the
five … a. yes, b. dunno, c. dunno what this means. d mock up. e. yes." Taken: (a) Spin the
wheel on the result; (b) the main button slot stays empty between asks; (c) the strip stays
between asks, dimmed; (d) frame 1 here, four slots on the left and folds on the right, with
"Your part now" at the top of the centre as Call & Answer's console shipped on 18 Oct;
(e) People ticks who has answered, by name.

The new request, same day:

> "when voting is done, as answers come in, or when their is an ask and ideas come in have
> the ability to consider an item where you get a choice to queue up to the room, or send to
> claude at any time. this does not remove the normal process flow, however, we need to mark
> any ideas, votes, in history as having been sent to claude … this mark could actually link
> to the history log showing where it went to claude code (and there you could see how it
> changed …) maybe there is a place for notes (or suggestions to the host to always tell
> claude why it was changed, so this lives in history"
