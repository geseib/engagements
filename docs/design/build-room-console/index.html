    • Fixed slots, fixed order: status · More · secondary · main · Host · Session. An empty slot keeps its width.
    • Status on one line, ellipsis, the full words in its title; the build link has a second line whose height is always kept.

    For the owner to answer before B8

    1. Settle's second button. On one screen the dock's second button is "Change before sending" (it opens the send window). On two screens the decide panel is already open, so the footer shows "Spin the wheel" there instead. Recommended: the console's footer uses Spin the wheel, and buildControls says which second button applies when the decide panel is inline, so the parity test still holds. If you would rather both say the same, the dock moves to Spin the wheel too.
    2. Between asks, the main button. The Stage has no main move between asks (unless mockups are ready). The footer shows an empty, held slot, and What's next's lead ("Open it") stays orange in the panel. Recommended: keep it empty, so the footer and the dock never disagree. The alternative is the footer leading with What's next's first move.
    3. The strip with no ask open. Between asks, during the run list and a talking point, the ask path has nothing live. The mockup keeps the strip, dimmed, with a plain label on the left ("Between asks", "The run list · 2 of 4 done"). Recommended: as drawn. The alternative is hiding the strip until an ask opens, which makes line 2 come and go.
    4. The rail's slots. C&A's rail has four slots. Build Room's Decided, Timeline, Asks, Screenshots and Room brief go to folds in the main area's side column, not to more rail sections; Points sits as a tab inside Later. Recommended: as drawn (the rail stays four, as C&A's). The alternative is a fifth rail section, "What happened".
    5. Names in People while the room votes. The laptop is private, so People ticks who has answered, by name, as C&A's does. It never shows what anyone chose. Recommended: as drawn. If you want Build Room's votes to feel more anonymous, People shows only the count while an ask is open.
