Joining a session

You do not need an account and you do not need to install anything. Everything happens in the browser already on your phone.

If there is a QR code on the screen

  1. Open the camera on your phone and point it at the code.
  2. Tap the link it offers.
  3. Type the name you want the room to see, and join.

If there is only a four-digit code

  1. Go to the join page.
  2. Type the four digits from the screen at the front of the room.
  3. Type your name, and join.

If somebody has sent you the whole join link, you can paste it into the code box — the four digits are taken out of it for you.

What you will see

When a question is asked, it appears on your phone at the same moment it appears on the front screen. Trivia gives you four options to pick from. Call and answer gives you a box to write in, and then, once everybody has written, a list of the answers to vote on.

If your name is already taken

Two people called Sam in the same room is a real problem for the standings, so the second one is asked to pick something else. Add an initial.

If you lose connection

Rejoin with the same code and the same name. Your answers and your score are still there; you pick up at whatever the room is doing now.

Keyboard

On a laptop, 1–4 select a trivia option and Enter submits it.

Still stuck? The help button inside a session shows this same guide without losing your place.
