Build Room, Crew mode: building with a room of Claudes

Storyboard for FLOWS.md in this folder. Nothing here is built. It continues the story from ../build-room/: the room is still building a volunteer sign-up site for the Eastside Food Bank, join code 4821, hosted by George. Three people brought laptops with their own Claude Code: Priya, Sam and Ana. They become builders, and the rest of the room keeps watching, reacting and deciding.

The principle. Engage carries the conversation and the evidence; git carries the code. Engage holds pointers (repo, branch, commit), summaries, screenshots, comments and decisions. It never needs a GitHub token or anyone's source. Each frame has a caption and one line on why it is drawn that way. Wall frames use the stage ladder at frame scale, so judge them full-width.

The same six questions as FLOWS.md §6. The amber bar marks the recommendation.

1

Which access modes in v1?

Patches through Engage + fork and pull request. Patches work in any room with no accounts; fork and PR is what real teams use.
All three. Branches on the host repo can follow later.
Recommended: patches + fork and PR
2

Should Engage ever talk to GitHub itself?

Not in v1. Everything goes through each Claude's own gh. No tokens, no webhooks.
A GitHub App. PR status, checks and comments mirrored both ways. Powerful, but tokens and webhooks.
Recommended: local-only, revisit later
3

Who may merge?

Only the host. One person decides what goes into the base.
The host plus named maintainers. Faster with a big crew; more people to agree.
Recommended: only the host
4

How public are peeks?

Shown when the host features them. Safer, and the host curates the wall.
Live to everyone as soon as shared. More energy, more noise.
Recommended: host features them
5

Running others' code

The host's Claude asks before every run. Builders' code stays untrusted.
The host trusts the crew for the session. Fewer prompts, more risk.
Recommended: ask every time
6

How big a crew?

2 to 8 builder lanes. What the board is drawn for.
More than 8. Needs grouping, for example one row per task.
Designed for: 2 to 8 lanes
