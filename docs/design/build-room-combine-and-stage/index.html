1One status, from one rule

Building: Claude has done something in the last 90 seconds (an edit, a command, a post). Waiting: Claude is listening and has done nothing for 90 seconds (S2). Paused: Claude has not been heard from for 2 minutes (S3). The host's header chip uses the same rule, so the wall and the laptop never disagree.

2What it is on, in words

The step from Claude's plan, or its newest progress post. "Since" is when that started, not when the last decision was made.

3One decision, not a feed

Only the latest decision, as question and answer. Everything else is on History.

4The dock says what the room can do

Not a second status. With Wi-Fi sharing on, it also says "Open the build on the same Wi-Fi".
