1The vote is a proposed ask with empty pictures

It behaves like one of Claude's proposed asks today: the room cannot see it, each option fills in as Claude calls share_image with its askId and letter, and the card counts "1 of 3".

2Three ways out while it waits

Open now, without the rest if Claude is slow or the room is ready (options without a picture show their words only, as today). Edit the question or the options. Cancel the vote: the ideas go back to the queue.

3The room is not left staring

The Stage keeps showing Claude at work, and Now says what it is doing: making the mockups.

4Ready: it opens itself (the default), or waits

Open-by-itself is on by default (owner, 2026-10-05). The last picture opens the vote and the ask pill appears in the header (and the room's screen can jump to Stage, owner question 3). Turned off for a vote, the card turns green and waits for the host, as drawn here.
