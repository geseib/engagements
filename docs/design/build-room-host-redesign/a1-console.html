1What it is good at

A host with an extended display, or on a video call sharing only the stage window, sees everything at once and never hides anything from the room.

2What it costs

A mirrored projector, the most common room set-up, shows this console to everyone: it then needs Present, which is today's problem. A second window must be opened and dragged to the right display every session. Two layouts to build and keep in step.

3What it would reuse

Every panel in it is a B drawer panel laid out in columns, so building B first loses nothing if A follows.
