The Session menu, simplified

Owner, 3 Nov 2026: "really think through how to provide all the functionality while simplifying the basic views here. advanced setting etc, could be in expanded sections. remember we want the first experience to be really simple and easy to navigate."

What ships: a Rounds tab holding the categories, the running order, a sixty-row question browser, the rounds so far with the report, and then twelve settings under "How the rounds run". An event adds an Agenda tab that holds one link. End session is its own tab. The Build Room's menu has two different tabs, and the phone has three more.

The proposal: five sections with the same names on every type: Up next · Rounds so far · Screens · Joining · How it runs. Each one opens on a short default view, and everything else sits behind one More options line at the bottom, which says what is inside. End session and Main menu move to the sheet's foot, so they show in every section. An event gets one line at the top of the menu instead of an Agenda tab. A type adds or removes sections; it never renames one. Mockup only; sample content invented.

1 · Up next: what the room does next, and nothing else

  1. The running order comes first. The round on screen is the first row, in quiet blue. Each row shows only ↑ ↓ and ⋯. Ask now, Put aside for this session and Remove are in ⋯ (fork F3).
  2. Write a question and Choose from the set are the two ways to add a round. Each one opens as a step inside this section with "‹ Up next" to go back, the way the composer works today. The 60-row browser is no longer drawn under the queue.
  3. Categories collapses to one line: how many are on and how many questions are left, with Change. Change opens More options, where the switches are.
  4. End session and Main menu are in the foot of every section. End session is no longer a tab of its own.

3 · More options opened, and the "Choose from the set" step

  1. How it runs › More options holds every remaining setting. Each keeps its explanation and its "From the next round" tag. On one screen, Workie's part stays behind Show on this screen, as it does today.
  2. Up next › More options: the category switches with their counts, the questions put aside for this session (each with Restore), and the session's goal.
  3. Choose from the set is a step, not a wall. It has search, one Category filter, and "Hide asked" on by default. Each row shows Queue and Ask next; Ask now is in ⋯ with its warning. "Correct answers are not on this screen" stays.

6 · Survey: Close survey takes Up next's place, and Rounds so far becomes Results

  1. A survey has no rounds. Its first section is Close survey: where it stands, the two-minute warning, and Close now. The confirm and the words are the ones that ship (SESSION_MENU_WORDS).

  3. The survey's feedback and Workie settings move from "After it closes" (under Close survey) into How it runs, the same home they have on every other type.
