# Desk reviews: the simplified Session menu

Three desk reviews of `index.html` (frames 1–10), each read as a particular person. Revisions marked **R** are already in the
mockup and the README. Those marked **Open** go to the owner as forks.

## 1. A first-time host (Call & Answer, two screens, never seen Engage before)

Walked through: open the menu mid-round, find the join link for a latecomer, then find what the room said in round 1.

- *Up next first is right.* "Running order" with the live round highlighted answered "what happens next" before I had to read
  anything. Write a question and Choose from the set are obvious.
- *I found the join link in one tap.* Joining is a word I would look for. Before, "Phone remote" sat next to it and I would
  have tried that first, because it has a QR code. **Folding the phone into Screens removes that wrong turn.**
- *"Rounds so far" found round 1 at once.* But before any round has been played, frame 2's report card with an "Open the report"
  button would be a dead end. **R5:** before round 1 the section says the report and rounds appear once a round is played,
  and draws no button (README D3).
- *"More options" with its list beside it* told me there was more without making me open it. I didn't need it.
- *"How it runs" is a slightly odd name.* After one look it was clear (names and pace). I tried "Settings" and "Options";
  both clash with §3.6 (Settings was retired as a name for this menu) and with "More options". Kept.
- *The red End session in the foot made me nervous* sitting next to Main menu. It is outlined text, not a filled button, it
  is at the opposite end of the foot from Main menu, and it confirms. Acceptable.

## 2. A weekly host (runs Call & Answer and Trivia every Friday, knows today's menu)

Walked through: reorder the queue, ask a question right now, switch a category off in Trivia, check a past round's read,
and change Workie's voice.

- *Reordering is the same, with fewer buttons.* ↑ ↓ on the row is what I use.
- *Ask now is one click further away* (in ⋯). I use it maybe once a session, and I have mis-clicked it before. That trade is
  fine. **Open (F3):** if the owner wants it back on the row, it goes in the browser step, not the running order.
- *Categories in Trivia:* I switch them often. "Change" opens the switches in one click, and More options then stays open
  for the rest of the session (README D2). Fine.
- *Past rounds:* exactly where I expect them, with the report on top. This is the tab I missed.
- *Workie's voice is two clicks deeper* (How it runs → More options). I set it once per session, so that is right.
- *Redo the read* is the thing I use in the middle of a round, and it should not be in a menu at all. **Open (F4):** move it
  next to the read itself. The menu copy stays until then.
- *I worried I'd lose Sign out.* Main menu → Home has it, and the session keeps running. Fine (F5).

## 3. The owner (wants simple, hates clutter)

Read frames 1, 2, 4 and 10 side by side with today's Rounds tab.

- *The first view is short.* Up next shows four rows, two buttons, one line and one expander. Today the same tab runs from
  categories, through 60 questions, to twelve settings.
- *Repeated facts.* Frame 1 said "23 questions left" twice: in the note under the running order and in the Categories line.
  That breaks the rule against stating one fact twice in a viewport. **R3:** the note now says "then the set carries on by
  itself"; the count lives only on the Categories line.
- *Noise in the foot.* "\ opens and closes" next to Main menu is a keyboard tip in the most important strip. **R1:** removed;
  it stays in Screens · More options under Keys.
- *Noise in the headings.* "Applies now" printed beside every heading reads as clutter. Only the exception ("From the next
  round") is worth saying. **R4:** "Applies now" is no longer printed.
- *The event line was two lines long* ("Leadership day · item 3 of 6 · the room is on item 2" wrapped). The session name is
  already in the top bar. **R2:** the line now reads "This event · item 3 of 6 · the room is on item 2", then Bring everyone
  here and ‹ Agenda.
- *No empty Agenda tab, and End session is not a tab.* That answers the complaint directly.
- *Consistency:* frame 10 shows one set of names across all seven formats and the phone. The Build Room losing "Players /
  Settings" is the biggest change, and the right one.
- *Asked:* could Joining fold into Screens to make four sections? Joining is the one thing a host does while a latecomer
  stands next to them, so it earns a name of its own. Kept at five.
