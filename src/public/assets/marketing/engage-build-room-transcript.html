Build Room walkthrough transcript

A narrated tour of Engage Build Room.

Build with the room

A Build Room connects a team to a Claude Code project. Here, five people are making a Connect Four game. The host opens the room, shares one code, and puts the work where everyone can see it.

Four views, one session

The same session has four useful views. Host runs the conversation. Stage keeps the current question visible. Build shows the working software. History keeps the choices, screenshots, and reasons behind the work.

Ask for ideas

The host starts with one clear question: what would make this game fun to play together? People answer from a phone, tablet, or laptop. Their ideas arrive in the room in real time.

Put the choice on Stage

Claude Code can offer working options instead of a long debate. The host puts the choice on Stage. Everyone votes from their own browser, and the result updates for the whole room.

Send one clear decision

The host reviews the result and writes one clear direction: keep the classic board, add a bold arcade theme, and make the next move easy to see. One click sends that decision to Claude Code.

Build and share

Claude Code builds while the team keeps talking. Progress, screenshots, and a working version come back into the room. The Build view gives everyone the same software to try, without passing links around.

Test, respond, improve

The team plays the game and sends quick feedback. A short poll settles the next change. The host sends the answer back to Claude, and the latest build appears for another round of testing.

Keep the record

History keeps every prompt, vote, decision, screenshot, and build together. The team leaves with working software and a clear record of why it took this shape. What will your room build?
